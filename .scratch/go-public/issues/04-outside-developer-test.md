# 04 — Outside-developer test

Status: ready-for-human
Blocked by: 03

## What to build

Run the deferred M5 exit test with 3–5 developers outside the project. This ticket replaces `.scratch/first-release/issues/12-m5-exit.md`. The maintainer chooses and recruits them. Each follows the README and starts a real task in their own repo without help. The coordinator observes and records results in Comments.

For each developer, record the version, repo and agent prerequisites. Time from following the first-run instructions to starting the first real task. Do not coach them. Record where they got stuck and ask whether they would keep using Stintwork. If help is needed, record a failed attempt. File findings as M8 tickets, then set M8's scope and size from the results.

## Acceptance criteria

- [ ] Comments record results for 3–5 outside developers: tested version, repo, prerequisites, time to first task, where they got stuck and whether they would keep using it.
- [ ] Each developer starts a real task in their own repo within a minute, without help. Failed attempts are recorded, not counted as passes.
- [ ] Each finding links to an M8 ticket, or has a recorded reason why no ticket is needed. M8 tickets use the local tracker conventions and dependency order.
- [ ] Only after the test ends, M8's scope and size are set from its findings and its work items are added to the roadmap.
