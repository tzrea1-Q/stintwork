# 09 — Simpler top bar

Status: ready-for-agent
Blocked by: none

## What to build

During the 2026-10-15 walk-through, the maintainer found the top bar cluttered. Move functionality where it naturally belongs, following ADR 0010 and `docs/agents/frontend.md`.

Coordinator decisions (settled):

- Keep only project name and branch, Needs you, Jump to (⌘K), and Settings in the top bar. Settings uses a gear and visible Settings/设置 label at wide widths; narrow widths use an icon with a matching tooltip. Remove the separate language button, Warnings button, milestone select and Setup chip.
- Settings is a shared DropdownMenu with a Language radio group (English / 简体中文, preserving language persistence) and Project setup… / 项目设置… with the ready/total count. The item opens the existing Setup dialog. An incomplete setup adds a warning dot with an accessible description to the gear. Closing either overlay returns focus to the gear. Rename the former zh-CN Setup chip label 设置 to 项目设置. Remove the convenience language menu from the drawer: Settings is language's single home.
- Below the Needs you sheet's attention items, show a separate Project warnings / 项目警告 section with existing warning paths, details and long-text handling. Warnings are not attention items: the button count remains the attention count, with a warning dot and warnings in its accessible name. Handle empty, warnings-only and attention-only states correctly. Update only the Attention item glossary entry, preserving its Avoid line.
- Turn the board toolbar's All milestones / selected milestone label into a shared milestone picker, retaining the Milestone accessible name, adjacent stats, truncation/full-name access and existing URL/state behavior.
- Preserve shortcuts and command-palette destinations, including existing milestone commands.

Scope: `packages/web`, the one `GLOSSARY.md` entry, tickets 07 and 09, and `docs/agents/frontend.md` only if a rule needs updating. No dependencies or commits. New files carry SPDX headers.

## Acceptance criteria

- [ ] The top bar contains only the agreed controls and fits on one row at 768 and 390px without wrapping.

- [x] Needs you preserves the attention count, announces warnings and shows distinct warning content below attention items with correct empty states.
- [x] The board milestone picker preserves filtering, URL/state, keyboard use and full long names; the command palette still reaches its existing destinations.
- [x] Behaviour tests cover moved controls, keyboard interaction, dismissal and focus return.
- [ ] Browser specs cover 1440, 1024, 768 and 390px in both languages, light/dark at 1440 and 390px, overlay readiness, layout checks and top-bar screenshots at each width.
- [ ] Comments record actual checks and coordinator browser results and screenshot/interaction review at 1440/390px in both languages before merging. The coordinator runs e2e because the agent sandbox cannot bind sockets.
